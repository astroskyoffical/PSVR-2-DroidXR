Repeating hardstyle pulses can support half- or double-time tempo estimates; the listed alternatives and confidence are diagnostics from that analysis, not certainty. These are not headset sensors or compatibility measurements, and cue labels have not been manually verified.

THE PROJECT

Built for the
edge of compatibility.

PSVR-2-DroidXR is an experimental toolkit for running PSVR 2 from rooted Android phones. The project explores LinkDoctor, display and USB integration, device-specific kernel patch guidance, and compatibility diagnostics for reproducing and porting the setup.
