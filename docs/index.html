THE ENGINEERING STORY

Made for a console.
Reconsidered for a phone.

Rooted Android creates a different route for hardware designed around a console. The project investigates those mismatched expectations and traces the interfaces, while a container-based path provides an author-reported demonstration milestone.

01 / UNDERSTAND

Start at the hardware

Reverse engineering begins with what each side expects: headset and phone have different assumptions.

02 / CONNECT

Trace the interfaces

Documented scope includes LinkDoctor, display and USB integration, kernel patch guidance, and compatibility diagnostics.

03 / EXTEND

Keep moving native

A container-based phone VR route has been demonstrated. Native Android remains work in progress.

Scope, plainly: this is an experimental toolkit; compatibility remains device-dependent.
