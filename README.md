# PSVR-2-DroidXR
An experimental toolkit for running PSVR2 from rooted Android phones. Includes LinkDoctor, display and USB integration, device-specific kernel patch guidance, and compatibility diagnostics for reproducing and porting the setup.

Explore the [DroidXR landing page](https://astroskyoffical.github.io/PSVR-2-DroidXR/) for project status, the engineering story, and optional audio-reactive visuals.
